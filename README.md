# Cascades Earth

Real Central Oregon terrain in Minecraft Java Edition at **1 block = 1 metre**, built from public elevation,
water and land-cover data. Walk from the Three Sisters down to Bend and the high desert at true scale.

## Download

Get **CascadesEarth-Launcher-x.y.z.zip** from the [Releases page](../../releases/latest).

1. Unzip it and run `Cascades Earth Launcher.exe` (Windows only).
2. Windows may show a SmartScreen warning because the launcher isn't code-signed: choose **More info, then Run anyway**.
3. Press **PLAY**.

You need Minecraft: Java Edition (26.3). The launcher keeps the mod up to date from this page.
The first visit to each area downloads map data, so keep an internet connection on.

## Data credits
